## 四、改稿时别忘的硬约束（都是踩过的）

1. **千星没有渐变**：火焰/光晕只能靠"多层图元叠"或**纯色格子**（→ 所以火用 DOOM 算法）。
2. **控件坐标是相对父控件中心的偏移，超出父矩形会被裁**：往容器外长的东西（火焰、大锤）
   必须放在**装得下它的容器**里，或直接挂根节点。（网页稿里踩过：`viewBox` 从 0 起，负坐标那段火焰整条消失。）
3. **素材库没有杯子/炮筒/锤子**：实物只能用基础形状拼 ——
   `100001` 方块（可拉伸不糊）· `100002` 圆 · `100003` 三角形 · `100006` 圆环。
4. **颜色按实物真实颜色**，不要按"分区印象"配（例：溴水是黄褐 `#F0B444`，不是紫）。
5. **`math.random` 不可用**（沙箱拦）→ 自己带 LCG 伪随机（还顺带可复现）。
6. **控件预算**：每组上限 1000；火焰 432 + 现有 UI ~250 ≈ 680。
7. **无头截图**：跑"无限动画"的页面会卡死/崩 Edge —— 稿子都支持 `#still`（定住一帧），
   `tools/design-shot.mjs` 会按需自动加。
