雪皇的后厨 · 实物：杯子 / 锥形炮筒

先定这两个"东西"长什么样。它们是后面所有演出的主角 —— 摇的是这个杯子、砸的是这个杯子、炮筒是甜筒那一道工序里"掏出来的那个筒"。
大中小三档是为了对齐千星里能用到的尺寸（工位卡内 / 大舞台 / 缩略）。

一、杯子（锥形饮料杯）

上宽下窄、杯口有一圈亮边、左侧一道高光；液体是梯形，液面高度 = 这一步的进度。
下面四个是同形状的四种内容物：清水 / 茶汤（琥珀）/ 溴水（紫）/ 四季春（绿）。

二、锥形"炮筒"

锥尖朝下、筒口朝上；筒口有一圈金属沿、中间是深色内壁；
握把是深色带刻纹的一段（"掏出来握在手里"的那截）；锥体上有斜向螺纹。右侧那个是点火状态（从筒口喷火）。

三、这两个东西怎么在千星里拼出来

素材库里**没有**杯子/炮筒的现成图，所以用基础形状拼。下面是每一块的对应关系（改的时候按这张表改）：

部件千星里用什么关键点
杯身（梯形）基础形状 100001 方块，用两块侧边条旋转出收口；或直接用一个方块拉成杯身再叠两条斜边方块**拉伸不糊**，适合做梯形侧边
杯口亮边100001 细长条（横向）比杯身亮一档，宽度略大于杯口
液体100001 竖条，高度按进度改 sizeDeltaY颜色用 SetColor 区分四种内容物
高光100001 细竖条，白色半透明一条就够，别加多
炮筒锥体100003 三角形基础形状里就有三角形，直接当锥体
筒口 / 握把 / 螺纹100001 圆角小条螺纹用 2~3 条斜条叠出来即可
点火火焰100002 圆（拉高）+ 颜色渐变不可用 → 用 2~3 个圆错位叠出火苗千星没有渐变，火苗靠"多个椭圆叠"
