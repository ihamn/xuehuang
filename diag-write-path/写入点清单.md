# 写入点改动清单（逐字，照抄即可）

> 目标：**每一处"写控件属性"都变成"检查过了错误"的写入**，失败就在日志里留一行。
> 原来的写法一律是 `pcall(function() ... end)`，**返回值没人看** —— 真机独有的报错完全不留痕。
>
> 记号：**★必须改**（每帧都走、最可能冻结画面）；**○可选**（只在建控件时走一次）。

---

## 0. 先放模块

把 `diag-write-path/diag.lua` 复制成 `lua/src/diag.lua`。

⚠️ 这个仓的打包器**自动收录 `lua/src` 整个目录**，所以：
- 新增一个源文件会让产物变大、**"模块数"哨兵断言 +1**（断言红了是**对的**，别为了变绿删断言，
  在断言旁边写一句"多了 diag.lua，诊断用"即可）；
- 诊断做完要**回退**：删掉 `lua/src/diag.lua` + 把下面所有改动还原。

## 1. `lua/src/view.lua`

### 1.1 引入（★）——在第 29 行 `local K = require('kitchen') ...` 之后插入一行

```lua
local K = require('kitchen')   -- 只为读"当前这步的进度"（只读快照，不碰玩法状态）
local D = require('diag')      -- ★ 诊断构建才存在；回退时一并删除
```

### 1.2 `setText`（★）——原文（约 66~73 行）

```lua
local function setText(c, s)
  if not c then return end
  s = tostring(s)
  if txtCache[c] == s then return end
  txtCache[c] = s
  pcall(function() c.text = s end)
end
```

改为：

```lua
local function setText(c, s)
  if not c then return end
  s = tostring(s)
  -- ★ forceWrite=1 时无视缓存，每帧强制写（作者给的排查技巧）
  if not D.forceWrite and txtCache[c] == s then D.cacheSkip('view.setText', c, s) return end
  txtCache[c] = s
  D.try('view.setText', c, s, function() c.text = s end)
end
```

### 1.3 `setStyle`（★）——原文（约 74~84 行）

```lua
local function setStyle(c, size, col)
  if not c then return end
  local key = tostring(size) .. '|' .. (col and (col[1] * 65536 + col[2] * 256 + col[3]) or 'd')
  if styleCache[c] == key then return end
  styleCache[c] = key
  pcall(function()
    if size then c.fontSize = size end
    if col then c.fontColor = Color.FromRGB(col[1], col[2], col[3]) end
  end)
end
```

改为：

```lua
local function setStyle(c, size, col)
  if not c then return end
  local key = tostring(size) .. '|' .. (col and (col[1] * 65536 + col[2] * 256 + col[3]) or 'd')
  if not D.forceWrite and styleCache[c] == key then D.cacheSkip('view.setStyle', c, key) return end
  styleCache[c] = key
  -- ★ 这里是全工程**唯一没有护栏的字号写入**（host.setFont 有 math.floor 兜底，这条没有）
  D.try('view.setStyle', c, size, function()
    if size then c.fontSize = size end
    if col then c.fontColor = Color.FromRGB(col[1], col[2], col[3]) end
  end)
end
```

## 2. `lua/src/host.lua`

### 2.0 引入（★）——在第 16 行 `local H = {}` **之前**插入一行

```lua
local D = require('diag')      -- ★ 诊断构建才存在；回退时一并删除
local H = {}
```

### 2.1 `H.setFont` 的字号（★，约 442 行）

```lua
  pcall(function() c.fontSize = size end)
```
改为：
```lua
  D.try('host.setFont.size', c, size, function() c.fontSize = size end)
```

### 2.2 `H.setFont` 的字色（★，约 443 行）

```lua
  if r then pcall(function() c.fontColor = Color.FromRGBA(r, g, b, a or 255) end) end
```
改为：
```lua
  if r then D.try('host.setFont.color', c, r, function() c.fontColor = Color.FromRGBA(r, g, b, a or 255) end) end
```

### 2.3 `H.setColor` 的图片色（★，约 423 行）

```lua
    pcall(function() c.imageColor = Color.FromRGBA(r, g, b, a or 255) end)
```
改为：
```lua
    D.try('host.setColor', c, r, function() c.imageColor = Color.FromRGBA(r, g, b, a or 255) end)
```

### 2.4 `H.setText`（★，约 428 行）

```lua
  if c then pcall(function() c.text = tostring(s) end) end
```
改为：
```lua
  if c then D.try('host.setText', c, s, function() c.text = tostring(s) end) end
```

### 2.5 `H.fitText` 的字号与尺寸（★，约 405~410 行）

```lua
  pcall(function() c:SetSizeDelta(w or (size * 12), h) end)
  pcall(function() c.fontSize = size end)
```
改为：
```lua
  D.try('host.fitText.size', c, size, function() c:SetSizeDelta(w or (size * 12), h) end)
  D.try('host.fitText.font', c, size, function() c.fontSize = size end)
```

### 2.6 `H.setAlpha` 的字色（★，约 464 行）

```lua
  pcall(function() c.fontColor = Color.FromRGBA(base[1], base[2], base[3], a or 255) end)
```
改为：
```lua
  D.try('host.setAlpha.color', c, a, function() c.fontColor = Color.FromRGBA(base[1], base[2], base[3], a or 255) end)
```

### 2.7 `H.setPos` / `H.setSize`（○，约 415~420 行）

```lua
  if c then pcall(function() c:SetAnchoredPosition(x, y) end) end
  if c then pcall(function() c:SetSizeDelta(w, h) end) end
```
改为：
```lua
  if c then D.try('host.setPos', c, x, function() c:SetAnchoredPosition(x, y) end) end
  if c then D.try('host.setSize', c, w, function() c:SetSizeDelta(w, h) end) end
```

### 2.8 建控件阶段的写入（○，可选但推荐）

`H.spawn` / `H.spawnBox` 里还有一批 `pcall(function() c.X = ... end)`：
`c:SetVisible`、`c.active`、`c:SetActive`、`c.name`、`c:SetImage`、`c.imageType`、
`c.bgColor`、`c.horizontalAlignment`、`c.verticalAlignment`、`c.enableOutline`、尺寸与位置。
它们**只在建控件时走一次**，失败会让界面"半建成"（同样被静默吞掉）。
要抓就把同一段里的 `pcall(function()` 依次换成 `D.try('spawn.<字段名>', c, <值>, function()`。

### 3.3 `afterAct` 的错误不再被吞（★，约 246 行）

```lua

```
改为：
```lua
      local okA, errA = pcall(V.sync, v, G.s)
      if not okA then D.afterAct(errA) end
```

### 3.4 `bootErr` 打一行（★）——`OnUpdate` 开头那句

```lua
  if not built then boot() end
  if bootErr then return end
```
改为：
```lua
  if not built then boot() end
  if bootErr then
    if not _bootLogged then _bootLogged = true; D.boot(bootErr) end
    return
  end
  if not _bootLogged then _bootLogged = true; D.boot(nil) end   -- 第一帧确认启动成功
```

```lua
  local okSync, errSync = pcall(V.sync, v, G.s)
```

```lua
  D.summary(_heart)          -- 每 30 帧一行 [WERR-SUM]（没错误就不打）
```
