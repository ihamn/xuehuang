# 杯子里放什么 · 操作 → 视觉映射（2026-10-01 设计稿）

> 要解决的问题（用户原话）：**"进行某个操作，杯子里液体增加；进行某个操作出现干冰；
> 进行某些操作增加配料"** —— 也就是把"玩家按了一下"翻译成"杯子里看得见的变化"。
> 本文只定**映射规则**；实现落在 `props.lua` 的杯子接口 + `recipes.lua` 每步的 `vis` 字段。

---

## 一、杯子能装的东西（内容槽）

| 槽 | 视觉表现 | 谁会用 |
|---|---|---|
| **液体** | 颜色（饮料真色）+ 液面高度 | 全部杯装产品 |
| **冰块** | 3~4 个小方块，浮在液面 | 干冰干柠檬水、四年陈酿喷火柠檬茶 |
| **柠檬片** | 1~2 个黄圆片（浮在液面） | 干柠檬片、四年陈酿柠檬片 |
| **果肉** | 几块橙色小块（摇匀后散开） | 蟠桃果肉、苹果 |
| **干冰** | 液面上方**白雾** + 液面**结霜白边** | 干冰干柠檬水（招牌） |
| **奶感** | 液体颜色**变浅变浑**（不是换色，是往白里混） | 奶精、牛奶 |
| **气泡/泡沫** | 液面一层浅色细泡 | 萃取、摇匀 |
| **杯口焦糖** | 杯口一圈褐色 + 余温微光 | 炙烤杯口（蟠桃） |
| **盖子** | 杯口盖上圆盖 | `pack` 封杯出餐 |

## 二、五条映射规则（按工位/手法）

| 规则 | 触发 | 杯子的变化 |
|---|---|---|
| **R1 注入 → 液面涨** | `brew`/`chem` 的 tap/hold（注入、加水、加满、取液、定容） | 液面 **+Δ**（每步一个数，见下表）；颜色向该步骤的"注入物"靠拢 |
| **R2 摇匀 → 颜色归一** | `shake` 的 mash（摇匀） | 液面不变；**未摇匀时液体分两层色带，每按一下上层/下层的界线模糊一点，满 N 下 → 完全均一** |
| **R3 压缩 → 状态切换** | `shake` 的 mash（压缩、继续压缩） | 液面**微降 + 波纹**；达到次数 → 出现**干冰/气泡**状态 |
| **R4 加料 → 出现配料** | `shake`/`chem` 的加料步（砸苹果、加果肉、加奶精、加冰） | **配料子件出现**（果肉块/冰块/柠檬片）；奶精则走"奶感" |
| **R5 火系 → 只动杯口** | `fire`（炙烤杯口） | 液体**不变**；杯口出现**焦糖圈**（+枪筒喷火那套演出） |

**未满 N 下时的反馈**（mash 类，最容易被玩家当成"没反应"）：
液面**微量上浮**（视觉上的"在涨"）+ 杯身抖动幅度随进度增大 + 进度条。
—— 一次按一下不能涨满，否则"次数"这个玩法就没了。

## 三、六个产品的逐步映射（`vis` 字段的值）

### 干冰干柠檬水（dryice，6 步）
| # | 步骤 | vis |
|---|---|---|
| 1 | 放入干柠檬片 | `add='lemon'` |
| 2 | 加水至七分满 | `fill=0.70, color='lemon'` |
| 3 | 双手握住杯子（hold） | `pulse='shake'`（只晃，不涨） |
| 4 | 压缩至 25000 千帕（mash6） | `pulse='ripple'` + 满 → `state='bubble'` |
| 5 | 继续压缩直至固态干冰（mash6） | 满 → `state='dryice'`（白雾 + 结霜） |
| 6 | 封杯出餐 | `lid=true` |

### 空杯满杯千溴水（bromine，4 步）
| # | 步骤 | vis |
|---|---|---|
| 1 | 量筒取 10ml 溴水原液（hold） | `fill=0.15, color='brom'`（浓，深） |
| 2 | 加满空杯至满杯（mash5） | 每按 +0.17（满 → 1.0），颜色略变浅（稀释） |
| 3 | 摇匀至颜色均一（mash4） | 走 **R2**：分层 → 均一；满 → `state='foam'` |
| 4 | 封杯出餐 | `lid=true` |

### 现萃速溶咖啡（instcoffee，5 步）
| # | 步骤 | vis |
|---|---|---|
| 1~3 | 取粉 / 放粉碗 / 按萃取（3 个 tap，noSlot） | **杯子不动**：这三步作用于**咖啡机**。杯子上只显示"空杯待用"+ 步骤提示 |
| 4 | 注入热水（tap） | `fill=1.0, color='coffee', state='steam'`（一次性大涨 + 热气） |
| 5 | 封杯出餐 | `lid=true` |

> ⚠️ 这条暴露一个通用问题：**有的步骤作用于器具、不进杯子**。反馈必须落在"器具"或"提示"上，
> 否则玩家按了三下，杯子毫无变化 —— 与"按键没反应"是同一种体验。

### 牛顿苹果奶绿（newton，5 步）
| # | 步骤 | vis |
|---|---|---|
| 1 | 把苹果砸进杯子（mash4） | 每按：果肉块落下 + 溅起；满 → `add='apple'` |
| 2 | 注入绿茶汤（tap） | `fill=0.55, color='tea'` |
| 3 | 加入奶精（tap） | `mix='milky'`（颜色往白里混一档） |
| 4 | 注入牛奶（hold） | `fill=1.0, color='milk'`（最终奶绿真色） |
| 5 | 封杯出餐 | `lid=true` |

### 蟠桃四季春（peach，4 步）
| # | 步骤 | vis |
|---|---|---|
| 1 | 注入四季春茶汤（hold） | `fill=0.70, color='tea'` |
| 2 | 炙烤杯口（hold） | `rim='caramel'`（走 R5，液面不动） |
| 3 | 加入蟠桃果肉并摇匀（mash5） | `add='peach'` + 每按颜色向 `peach` 靠拢（满 → 桃色） |
| 4 | 封杯出餐 | `lid=true` |

### 白芝麻火麒麟（qilin，2 步）
**不进杯子**（它是一支甜筒）：掏出枪筒 → 枪筒冒火 → 整支带火出餐。走的是炮筒那一套。

## 四、接口（`props.lua` 的杯子要给什么）

```lua
cup.setFill(frac, rgb)          -- 液面 + 颜色（颜色可省略 = 不变）
cup.setMix(kind, t)             -- 混合度 0..1：'milky'（往白里混）/ 'uniform'（摇匀归一）
cup.addTopping(kind, n)         -- 'ice' | 'lemon' | 'peach' | 'apple' …（返回句柄，便于逐个点亮）
cup.setState(kind, on)          -- 'dryice' | 'bubble' | 'foam' | 'steam'
cup.setRim(kind)                -- 'caramel'
cup.setLid(on)                  -- 盖子
cup.pulse(kind)                 -- 一次性动效：'shake' | 'ripple' | 'splash' | 'flash'
```

**规则写在哪**：`recipes.lua` 每一步加 `vis = {...}`（见第三节的表）。
好处：**改配方不用改代码**；`view.lua` 只当执行者，不做判断。

## 五、控件的账（三角方案之后才做得到）

| 件 | 数 |
|---|---|
| 杯子本体（三角+遮挡+液面线+杯口+高光+底边+根） | 8 |
| 配料（冰块 4 + 柠檬 2 + 果肉 5 + 雾 1 + 盖 1） | 13 |
| **一杯合计** | **≈ 21** |

4 个工位同时各有一杯 = 84 控件（旧叠条方案光本体就要 208）。⇒ **这套内容系统在预算内做得起。**

## 六、待用户确认的三件事

1. **液面增量**按"每一步一个数"给（如"加水至七分满"=70%），还是按"注入了多少 = 剩余空间的比例"自动分？
2. **未摇匀的分层色带**（让"摇匀"看得见）要不要？奶精的"往白里混"要不要？
3. **作用于器具的步骤**（咖啡前三步）怎么反馈：杯子显示"待用+提示"，还是要给咖啡机做实物件？
